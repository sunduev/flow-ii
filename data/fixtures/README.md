# Тестовые данные из XLSX

Набор подготовлен 2 октября 2026 года из `tournament-with-players-12826.xlsx`. Все ID, имена игроков и основные названия команд взяты из таблицы. Годы, название турнира и межгодовые события **условные**: это материал для тестов кода и интерфейса, не история реальных проведений. Реальные годы уже подключены в M4; демонстрационный набор хранится отдельно и не подменяет рабочий JSON сайта.

| Файл | Содержимое |
| --- | --- |
| [source-snapshot.json](source-snapshot.json) | Вся таблица: 90 команд, 574 игрока, 90 участий; условный год 2026 |
| [demo-history.json](demo-history.json) | Сохранённый набор M1–M3 для тестов: 6 условных лет, 90 команд, 574 игрока, 540 участий |
| [history-scenarios.json](history-scenarios.json) | Ожидаемые результаты для тестов цепочек и UI |

Схема версии 1 описана в [контракте](../../docs/data-contract.md). Проведение содержит `id`, `year`, `name`. Город и флаг не перенесены; имена сокращены до «Фамилия И.» без отчества. Дробные места и все игроки составов от 6 до 9 сохранены в снимке. В M4 демонстрационная история перенесена в `demo-history.json`, чтобы тесты не зависели от обновления рабочего JSON сайта. Преобразователь — `scripts/convert-xlsx.ts`.

Снимок сохраняет исходные места, названия и составы; добавлены только условные год и название проведения. В `demo-history.json` год 2026 полностью совпадает со снимком. Изменения относятся к более ранним условным годам.

## Порядок лет

Проведения/участия JSON и полные вычисленные цепочки: **2020 → 2021 → 2022 → 2024 → 2025 → 2026**.

Колонки диаграммы слева направо: **2026, 2025, 2024, 2022, 2021, 2020**. 2023 отсутствует; его нельзя дорисовывать или назначать игрокам команды на этот год. Пунктир означает пропуск игроком проведения, которое есть в наборе: 2022 → 2024 для игроков «Брутер А.» и «Семушин И.» сплошные, а 2021 → 2024 для игрока «Руссо М.» пунктирный из-за отсутствия его участия в 2022.

## Сценарии

| Игрок | Ожидаемая история по годам |
| --- | --- |
| Брутер А. (`4270`) | 2020: `49804` → 2021: `27177` → 2022: `75592` → 2024: `27177` → 2025: `49804` → 2026: `49804` |
| Руссо М. (`27403`) | 2020: `49804` → 2021: `49804` → 2024: `49804` → 2025: `49804` → 2026: `49804`; в 2022 участия нет |
| Семушин И. (`28751`) | Команда `49804` во всех шести известных годах |

Для игрока «Брутер А.» проверяются смена команды и возвращения. Переходы созданы обменом с игроком ID `15727` в 2021/2024 и игроком ID `23629` в 2022; у каждого игрока одно участие на проведение. В 2022 у игрока «Руссо М.» участия нет; состав `49804` содержит пять игроков. Это намеренный сценарий отсутствия игрока, статус неполноты не вводится.

У команды `49804` в 2020/2021 условное название «Борский корабел (тестовое прежнее название)», позднее — «Борский корабел». ID сохраняется. Места первых трёх команд меняются между годами для проверки положения узлов; остальные места сохранены.

Есть совпадающие фамилия и имя у разных игроков: «Зайцев А.» (`147115`, `159877`) и «Губин А.» (`80561`, `8372`). Их сокращённые подписи совпадают; истории остаются раздельными по исходным ID. Место команды `4109` в 2026 — `6.5`; не округлять его.

Начальный выбор: `2026:49804`, весь состав — `27403`, `28751`, `30270`, `33620`, `37761`, `4270`.

Для истории до и после выбранного года выбрать `2024:27177`, затем игрока `4270`. После сужения диаграммы до 2025–2026 выбранное участие и игрок остаются прежними, вычисленная полная история содержит все шесть участий. В диапазоне есть только исходная связь 2025 → 2026; новые связи фильтр не создаёт. В нынешнем UI текстовых списков истории нет; для повторного открытия карточки состава нужно вернуть 2024 в диапазон.

Набор использовался в M1–M3 и сохранён для тестов. Он не заменяет реальные исторические XLSX и не подтверждает реальные переходы игроков. Рабочая история `public/data/chr/history.json` содержит 21 реальное проведение за 2001–2019, 2025–2026 годы; актуальный объём рабочих наборов указан в [контракте данных](../../docs/data-contract.md).
