# Исходные XLSX

Сюда кладутся все ежегодные выгрузки ЧР, без подпапок по годам.

XLSX исключены из Git и его истории; этот каталог в клоне содержит только README. На рабочем компьютере исходники сохраняются локально. Для `npm run convert:xlsx` нужно отдельно получить таблицы и разместить их здесь; готовый JSON уже хранится в репозитории, поэтому обычная сборка сайта не требует XLSX.

Имя: `tournament-with-players-<tournamentId>-<year>.xlsx`.
Пример: `tournament-with-players-1710-2011.xlsx` — ID источника `"1710"`, год `2011`. Скрипт извлекает оба значения из имени; название проведения задаётся в `data/tournaments/chr/sources.json`. Год в списке не дублируется.

Образец уже представлен как `tournament-with-players-12826-2026.xlsx`. Всего предоставлено 21 файл: 2001–2019, 2025–2026. Отсутствующие годы не заполняются.

Преобразователь: `scripts/convert-xlsx.ts`, команда `npm run convert:xlsx`. Добавление файлов не запускает импорт автоматически: нужна запись с названием в списке источников и запуск команды. Все 21 файл перечислены в data/tournaments/chr/sources.json с названиями «ЧР — <год>». Правила таблиц — в [контракте данных](../../../../docs/data-contract.md), обновление — в [README](../../../../README.md#подготовка-и-обновление-данных).
