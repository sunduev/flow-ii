## Договорённость о формате

Формировать подпись из **отдельных колонок XLSX**, а не разбирать объединённое ФИО:

- Убрать крайние пробелы у `Имя` и `Фамилия` существующим способом чтения ячеек.
- Сохранить целиком содержимое `Имя`, включая составное имя, дефисы и `ё`.
- Взять первый Unicode code point непустой фамилии, привести к верхнему регистру и добавить точку. Для составной фамилии всё равно одна буква.
- Результат: `${firstName} ${initial}.`; отчество не участвует, его значение не должно попасть в выходной объект или дополнительные поля.
- Для пустой фамилии вернуть только имя; для пустого имени — только инициал фамилии с точкой; для двух пустых полей — пустую строку. Не добавлять проверки допустимости данных или новые сообщения о «неполноте».
- Справочное имя одного ID по-прежнему берётся из последнего проведения. Порядок, ID, все составы, места, годы и названия команд сохраняются.

Примеры для тестов — вымышленные входные значения, явно помеченные как синтетические: фамилия `Тестов`, имя `Иван` → `Иван Т.`; `Демо-Пробный`, `Анна-Мария` → `Анна-Мария Д.`; `Ёлкин`, `Пётр` → `Пётр Ё.`. Колонка отчества может содержать синтетическое значение, но результат от него не зависит. Не переносить реальные полные ФИО игроков в тесты нового форматтера или отчёт.

Структура JSON и `schemaVersion: 1` сохраняются: поле `players[].name` становится отображаемым сокращённым именем. ID остаются строками, включая ведущие нули. Совпадение сокращённых имён никогда не объединяет игроков.
