# Независимые истории N турниров

5 октября 2026 года. Поручение: общий интерфейс для N независимых турниров; ЧР на `/flow-chr/chr/`; старый адрес перенаправляет на ЧР. Между турнирами нет навигации, общих историй или загрузки чужих JSON. Публикация и Git-команды не поручены.

## Решение

Реестр `data/tournaments.json` содержит ключ, название, путь списка XLSX и путь готового JSON каждого турнира. Во время запуска Vite из единого `index.html` создаются HTML-страницы в игнорируемом `.site/`. Vite собирает их как многостраничный сайт с общими JS/CSS. В HTML страницы передаются только название и адрес её JSON; реестр и исходники в браузер не загружаются. Корневая страница содержит только перенаправление на ЧР.

Для каждого турнира: `data/tournaments/<slug>/source/`, `data/tournaments/<slug>/sources.json`, `public/data/<slug>/history.json`. Схема версии 1 и вычисления истории сохраняются; ID из разных JSON независимы. CLI выбирает один турнир; двухаргументный режим произвольных входного/выходного путей сохраняется. Сборка не запускает преобразование и не требует XLSX.
