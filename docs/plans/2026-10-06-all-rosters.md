# Все составы команды

Согласовано в чате: отдельный выключенный по умолчанию переключатель «Все составы» рядом с «Компактно» объединяет уникальных игроков всех участий по teamId и показывает их полные истории. Период ограничивает только диаграмму. Компактность независима. Выбор другого участия сохраняет режим и сбрасывает фильтр игрока, как прежде.

Карточки той же команды показывают полный состав конкретного года с выбором игрока. Внешние карточки показывают только игроков из выбранного исторического набора, с учётом фильтра; подпись — «Из составов …». Дополнительные участия, не входящие в истории игроков активного года, имеют пунктирную рамку; при пересечении обеих групп рамка сплошная. Цвета и пунктир линий сохраняют прежние значения.

Рутинное решение: при выключении режима сохранять фильтр, если игрок есть в активном составе; иначе сбрасывать его. Цвета в общем режиме стабильны для одной команды независимо от активного года и фильтра.
