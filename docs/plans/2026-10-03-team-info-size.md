## Результат и проверки

Кнопка и её контейнер 32×32; вертикальная позиция совпадает с прямоугольником команды, правый край тоже. Под название освобождено ещё 8 px. Это уточняет размер 40×40 из предыдущего плана кнопки.

В браузере для ff 2025: кнопка и строка y=381,984375, высота 32, правый край 663; область больше не выступает. Наведение подсвечивает кнопку без открытия карточки. Нажатие мышью и Enter открывают карточку шести общих игроков, выбранная команда остаётся ff 2026. Escape закрывает и возвращает фокус. Размер 390×844: область также помещается в строку, переполнения страницы нет; карточка открывается снизу в пределах x=12…363, нижний край 832. Это проверка viewport, без физического телефона. Размер окна восстановлен. Консоль без ошибок и предупреждений.

`npm test`: 27/27; `npm run build`: TypeScript и production-сборка проходят; `git diff --check`: без замечаний. Геометрия и CSS проверены в браузере без искусственного unit-теста. Новых зависимостей нет. В приложение варианты символов не добавлялись: текущий ⓘ сохранён.
