# Отдельная строка выбора и фильтр игрока

По двум комментариям пользователя вынести выбор в отдельную строку, удалить отдельную кнопку «Состав» и кнопки «Весь состав». Игрок — активный фильтр с крестиком; удаление или повторное нажатие на имя возвращает цепочки состава. Название команды с годом в новой строке открывает состав, сохраняя доступ при скрытом году.
