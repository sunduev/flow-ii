5 октября 2026 года. Согласовано: Vite собирает один исходный `index.html`; после сборки готовый HTML размещается по каталогам турниров. JS выбирает JSON по пути. Сохраняются адреса, отдельные истории, названия страниц, корневое перенаправление, прямое открытие и перезагрузка. Публикация и Git-команды не поручены. Незакоммиченные изменения предыдущей задачи сохраняются.

## Решение

Убрать `.site/`, отдельный root Vite, алиас `/src` и список HTML-входов. `scripts/site-pages.ts` после сборки читает готовый `dist/index.html`, создаёт копии с названием каждой серии и корректными путями к ресурсам, затем заменяет корень страницей перенаправления. Подключить шаг через завершающий build-hook Vite, чтобы обычная команда и `--base=./` работали без отдельных ручных команд.

В общий JS передавать только публичные настройки маршрутов: slug, name, history и ключ серии по умолчанию. Списки XLSX и готовые истории в bundle не входят. `src/model/tournament-page.ts` выбирает серию по точному пути; неизвестный путь не запускает fetch. URL JSON разрешается относительно каталога сайта, определённого по URL общего модуля в `src/` при dev или `assets/` в сборке. В dev используется обычный fallback Vite, в preview — существующие статические страницы. Нормализацию адресов без слеша сохранить.
