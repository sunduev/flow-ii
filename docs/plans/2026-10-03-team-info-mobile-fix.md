# Мобильная карточка исчезает после открытия

Исходное наблюдение пользователя: на телефоне карточка связанных игроков появляется и сразу исчезает. В браузере воспроизведено: открыть карточку на 390×844, изменить высоту до 800 при прежней ширине — карточка закрывается. Причина этого сценария: безусловный `hide()` на `resize`. Физический телефон пока не проверен.

## Результат

Правила событий выделены в `src/diagram/team-info-events.ts`, подключены к контроллеру и покрыты тремя сценариями в `tests/team-info-events.test.mjs`. Перед исправлением две проверки падали с `true !== false` (мобильная высота и прокрутка страницы). После исправления `npm test`: 30/30; `npm run build`: TypeScript и Vite успешно; `git diff --check`: без замечаний. Новых зависимостей нет.

Браузер: 390×844 → 390×800 → 390×844 сохраняет открытую карточку; нижний край на 800 равен 788. PageDown прокручивает страницу до scrollY=537 без закрытия. ArrowDown в диаграмме меняет scrollTop 0 → 38 и закрывает карточку. Крестик и Escape закрывают, фокус возвращается на кнопку. Смена ширины 390 → 844 закрывает. Десктоп 1280×720: Enter открывает, изменение высоты до 680 закрывает. Выбранный состав сохраняется. Консоль без ошибок/предупреждений, viewport восстановлен.

Это воспроизведение через изменение viewport и клавиатуру в браузере, без физического телефона и эмуляции touch. Модель телефона/браузер пользователя пока не уточнены; подтверждение именно его исходного сценария на устройстве остаётся за пользователем. Исправление не закоммичено и не опубликовано.
