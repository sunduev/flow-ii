## Результат и проверки

Добавлены `src/diagram/team-tooltip.ts`, `tests/shared-roster.test.mjs`; обновлены `src/history/selection.ts`, `src/main.ts`, `src/style.css` и README. Данные, линии и выбор команды при наведении не меняются. Подсказка использует один HTML-блок, сравнивает составы по ID, сохраняет полный формат имени и различение одинаковых ФИО. Активная и несвязанные команды не получают список общих игроков.

TDD: новый тест сначала завершился ошибкой отсутствующего экспорта `getSharedRosterPlayerIds`; после реализации три сценария проходят. Итоговый `npm test` — 27/27. `npm run build` — TypeScript и Vite успешно; JS 19,73 kB, CSS 4,36 kB до gzip. `git diff --check` — без замечаний. Локальный `npm run dev` запущен с разрешением на порт после EPERM в sandbox.

Браузер, реальный рабочий JSON: 1280×720 и 1280×420. Проверены наведение с задержкой, переход курсора на подсказку, Escape и восстановление обычного SVG title, клавиатурный фокус, Enter для выбора другой команды, полный/компактный режимы, один игрок, несвязанная команда, скрытый выбранный 2026 год, закрытие при прокрутке и смене диапазона. Для Борского корабела 2025 показаны все шесть игроков выбранного состава 2026, для Борского корабела 2019 — четыре; для Эрудитов 2019 — Дмитрий С., для Совы при свете дня 2019 — Руслан Х.. При выборе Максим Р. остаётся одно имя. Подсказка умещается в проверенных окнах и переносится влево у правого края. Ошибок/предупреждений в консоли не обнаружено; viewport восстановлен.

Воспроизведён и исправлен сценарий фокуса после автоматической прокрутки: показ отложен на два кадра, чтобы измерить окончательную позицию; повторная браузерная проверка проходит.
