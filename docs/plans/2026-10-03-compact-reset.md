# Компактный переключатель

Пользователь отменил кнопку «Сбросить» во время работы. Итоговая задача: вместо двух кнопок один toggle «Компактно» (aria-pressed), пояснение «Только связанные команды» без диапазона и технических подробностей. Выбор и полная история сохраняются при переключении; возврат к общей таблице восстанавливает прежнюю прокрутку. Кнопка «Все годы» остаётся.

План: заменить элементы и обработчики, убрать отменённую логику сброса; проверить тесты/сборку, браузер и документацию.

Выполнено: один переключатель и короткое пояснение, кнопка сброса и её код отсутствуют. npm test 23/23; npm run build, включая TypeScript, успешно. Браузер: Enter включает compact (49 узлов выбранного состава), повторный Enter возвращает 1240 узлов; статус «Только связанные команды», reset-filters отсутствует. git diff --check без замечаний.

Дополнение: по новому комментарию пользователя пояснение под переключателем удалено вместе с его DOM-элементом, aria-describedby, обновлением текста и CSS.
