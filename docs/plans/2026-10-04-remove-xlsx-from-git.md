# Удаление XLSX из Git перед публикацией

Дата: 4 октября 2026 года. По поручению пользователя удалить XLSX из всей истории, сохранив локальные файлы и готовый JSON.

## План

- [x] Проверить чистоту рабочего дерева, ветки и remote; сохранить проверенную резервную копию Git и 20 XLSX вне проекта. Исходная ветка `main` содержит 14 коммитов, remote отсутствует.
- [x] Добавить `*.xlsx` в `.gitignore`, убрать XLSX из индекса без удаления локальных файлов, описать работу клона без исходников и закоммитить подготовку.
- [x] Переписать историю ветки и служебные снимки Git, удаляя только XLSX. До обновления ссылок сравнить все остальные файлы каждого преобразованного дерева и метаданные коммитов. Удалить старые локальные ссылки восстановления и недостижимые объекты после проверки резервной копии.
- [x] Проверить отсутствие XLSX в доступной истории и индексе, сохранение 20 локальных файлов по SHA-256, неизменность готового JSON и кода, чистоту рабочего дерева. Проверить, что клон без XLSX выполняет тесты и production-сборку.

## Границы

История сохраняет сообщения, авторов, даты и порядок коммитов; хеши меняются. ФИО и ID игроков в JSON сохраняются. Публикация и push не выполняются. Резервная копия исходной истории содержит XLSX и остаётся вне публичного репозитория.

## Выполненные проверки

- `git bundle create … --all`, копирование исходников и `git bundle verify …` — полная резервная копия Git и всех локальных таблиц сохранена рядом с проектом, вне репозитория; bundle проверен.
- Одноразовый Python-скрипт через штатные команды Git преобразовал 15 коммитов (14 прежних и коммит подготовки) и 132 дерева, атомарно обновил 17 ссылок, включая служебные снимки Codex. Перед обновлением ссылок проверены неизменность всех файлов, кроме XLSX, авторов, дат, сообщений и остальных метаданных. Скрипт и таблица соответствия хешей не включены в проект.
- `git reflog expire --expire=now --all`, `git gc --prune=now`, `git fsck --full` — выполнены успешно; старые объекты XLSX удалены из локальной базы Git, исходная история доступна во внешнем bundle.
- `git ls-files '*.xlsx'` и поиск XLSX в `git rev-list --objects --all` — пусто. `git check-ignore` подтверждает игнорирование всех 20 локальных XLSX. Их SHA-256 совпадают с резервной копией; готовый JSON сохранил прежний blob ID.
- `git clone --no-local` в отдельный временный каталог — клон не содержит XLSX. Для проверки использованы уже установленные зависимости через ссылку на `node_modules` рабочего проекта, без повторной установки пакетов.
- В этом клоне `npm test` — 51/51; `npm run build` — успешно, включая TypeScript приложения и скрипта. Тесты преобразования создают собственные временные XLSX и не требуют исторических исходников.
- `git diff --check` — без замечаний. Документация описывает получение локальных исходников отдельно от сборки и публикации готового JSON. Браузерная приёмка не повторялась: код приложения и данные сайта не менялись.
