# Масштаб диаграммы кнопками

Согласовано: `− / текущий масштаб / +`, средняя кнопка возвращает 100%. Жесты touch остаются нативными. Масштабируется существующий SVG через CSS transform, без вызова renderer при нажатии кнопок. Обёртка ограничивает область прокрутки фактическим масштабированным размером. Центр видимой области сохраняется в пределах доступной прокрутки. Диапазон 25–200%, начальное значение 100%; масштаб сохраняется при выборе команды/игрока, смене периода и «Компактно». Карточка состава закрывается при смене масштаба.
