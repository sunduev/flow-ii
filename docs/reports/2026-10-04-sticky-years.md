# Закреплённые годы и Tab

Годы перенесены в отдельный SVG внутри sticky-слоя общей области прокрутки. По горизонтали заголовки и команды двигаются одним контейнером; масштаб применяется к обоим SVG. Нулевая высота слоя сохраняет координаты команд и расчёт центра зума. Белый фон закрывает проходящие под годами строки.

Узлы команд получили tabindex=-1: Tab пропускает все команды. Выбор мышью/касанием сохранён, программный фокус и Enter/Space остаются. По текущему решению пользователя выбор произвольной команды с клавиатуры больше не предоставляется; это уточнение записано в docs/plan.md. Ссылки годов, кнопки состава, игроки и управление сохраняют клавиатурный доступ.

Изменены src/diagram/index.ts, src/diagram/zoom.ts, src/style.css, tests/diagram-zoom.test.mjs и актуальная документация. Регрессионный тест масштаба заголовка сначала упал на отсутствующем размере, затем прошёл. npm test — 51/51; npm run build — успешно, включая typecheck приложения и скриптов; git diff --check — успешно.

Браузер Codex, production preview, полный реальный набор: после вертикальной прокрутки scrollTop=1319 заголовок остаётся на 1 px ниже верхнего края контейнера. При горизонтальной scrollLeft=1382 координаты x заголовка и узла первой колонки совпали (-1343). При 80% оба SVG имеют scale(0.8). На размере 390×844 после scrollTop=1784 годы также закреплены; ширина страницы 390 без внешней горизонтальной прокрутки. Выбор Hangover 2015 мышью меняет выделение; Tab после последней ссылки года переходит к кнопке связи, пропуская узлы. Enter на кнопке выбранного состава открывает карточку с шестью игроками и местом 65,5. Escape закрывает её. Мобильный viewport сброшен после проверки.

Физический телефон и другие браузеры не проверялись. Публикация не выполнялась.
