# Более узкие колонки

Весь текст интерфейса установлен в 12 px. Зум расположен перед «Компактно» в DOM и порядке клавиатурного обхода. Узлы — 220 px вместо 294, шаг колонок — 256 px вместо 330; линии и кнопки состава согласованы с шириной. На текущем desktop помещаются пять полных колонок вместо четырёх. Названия средней длины помещаются полностью; длинные сохраняют многоточие, title и aria-label. Место перенесено в карточки выбранного и связанного участия, дробная часть показывается с запятой.

Изменены src/style.css, src/diagram/geometry.ts, src/diagram/index.ts, src/diagram/team-info.ts, index.html, tests/diagram-view.test.mjs и docs/plan.md.

Проверки: npm test — 50/50; npm run build — успешно, включая npm run typecheck. git diff --check — успешно. В браузере проверены вычисленные размеры шрифтов 12 px, узлы 220 px, порядок управления, открытие карточки с местом, Enter для переключения компактного режима и Escape для закрытия карточки. На 375×812 ширина страницы 375 px, карточка остаётся внутри экрана. Временный viewport сброшен.
