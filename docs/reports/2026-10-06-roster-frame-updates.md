# Обновление карточки раз в кадр и цвет значка

Обновления из window.scroll/resize и visualViewport.scroll/resize объединены через requestAnimationFrame. За кадр выполняется одна отложенная операция с актуальным состоянием. При закрытии ожидающий кадр отменяется, скрытая панель не ставит его в очередь. Первое открытие остаётся синхронным.

Повторные getComputedStyle и offsetWidth/offsetHeight заменены кэшем: новое содержимое или доступный размер требуют нового измерения. На телефоне getBoundingClientRect кнопки больше не нужен. Неизменившиеся left/top не записываются. При реальном изменении размеров остаётся необходимое измерение после установки width/maxHeight; полного устранения layout-чтений не требуется. Профилирование времени на физическом телефоне не выполнялось, численного ускорения не заявляем.

Кнопка связи золотистых узлов окрашена #8b692a, её hover/раскрытый фон — #b89a5b22. Зелёные и активные кнопки сохраняют свои оттенки. Кнопка является соседом SVG-узла, поэтому цвет задаётся её собственным классом other-team.

- Новый тест очереди до реализации падает из-за отсутствия createFrameUpdate. После реализации два теста подтверждают объединение десяти событий, актуальное состояние, следующий кадр, отмену и новую очередь после отмены.
- Затронутые тесты: 13/13; полный npm test: 70/70.
- npm run build: TypeScript и production-сборка проходят; git diff --check без замечаний.
- ЧР, 1280×900: значок «Эрудиты, 2019» rgb(139,105,42), раскрытый фон rgba(184,154,91,0.133). Состав содержит игрока «Дмитрий С.»; внешний клик закрывает панель.
- ЧР, 390×844: панель x=12…378, y=481…832. Перетаскивание меняет scrollTop 0 → 120, панель остаётся открытой с нижним краем 832. Изменение высоты до 800 переносит нижний край на 788. Enter на игрока «Максим Р.» сохраняет панель и фокус на имени; Escape закрывает и возвращает фокус на кнопку состава.
- Консоль без ошибок/предупреждений; временный viewport сброшен. Нативный pinch на физическом телефоне не проверен, геометрия ×3 покрыта прежними тестами.
