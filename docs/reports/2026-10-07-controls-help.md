# Подсказки по фильтрам и зуму — 7 октября 2026

Выполнено по [плану](../plans/2026-10-07-controls-help.md). В строке статистики ЧР и СтудЧР добавлен значок «i». Короткая памятка объясняет «Компактно», «Все составы», фильтр игрока, кнопки масштаба, сброс процента, Alt/Option + колесо, два пальца на телефоне и двойной клик.

Использован нативный `popover="auto"` без дополнительного JS и зависимостей. Кнопка имеет доступное имя, панель — роль немодального диалога и заголовок. Открытие переводит фокус на крестик; крестик, повторное нажатие значка, Escape и нажатие снаружи закрывают памятку. Escape и крестик возвращают фокус на значок. Размер ограничен экраном, длинный текст прокручивается.

Изменены `index.html`, `src/style.css`, `src/main.ts`, README и основной план. Добавлены план задачи и этот отчёт. Данные, вычисления и обработчики фильтров/зума не менялись.
