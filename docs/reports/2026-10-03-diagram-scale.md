# Масштаб диаграммы кнопками

Добавлены «− / текущий процент / +» с уровнями 25, 33, 50, 67, 80, 100, 125, 150, 200%. Нажатие процента возвращает 100%; крайние кнопки отключены на границах. Центр видимой области сохраняется в пределах доступной прокрутки. SVG масштабируется через transform; обёртка с overflow clip задаёт фактическую область прокрутки. Нажатия кнопок не вызывают renderer и не заменяют узлы. При изменениях выбора/периода/режима новый SVG сразу получает текущий масштаб. Карточка состава закрывается при зуме. Сохранённая прокрутка общих результатов учитывает изменение масштаба в компактном режиме. Touch-события не перехватываются.

Изменены: `src/diagram/zoom.ts`, `src/diagram/index.ts`, `src/main.ts`, `src/style.css`, `index.html`, `tests/diagram-zoom.test.mjs`, `tsconfig.test.json`, README, описание диаграммы, `docs/plan.md` и план задачи. Данные, геометрия команд и правила истории прежние; зависимости не добавлялись.
