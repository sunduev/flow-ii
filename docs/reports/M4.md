# Отчёт M4 — преобразователь XLSX

2 октября 2026 года. Статус: завершён; обязательные критерии выполнены на всех предоставленных XLSX.

## Результат

Реализован `scripts/convert-xlsx.ts`, команда `npm run convert:xlsx`. Скрипт читает список источников, извлекает строковый ID источника и год из имени XLSX, обрабатывает проведения по возрастанию года и пересоздаёт JSON версии 1. Пути таблиц относительны к списку; читается выбранный или первый лист.

Колонки читаются по заголовкам, пустые строки пропускаются, команды группируются независимо от соседства строк. ID превращаются в строки, крайние пробелы удаляются, отчества и все игроки сохраняются, город и флаг игнорируются. Место и историческое название — из первой строки группы. Справочники обновляются по последнему проведению и сортируются по строковым ID; участия — по году/месту/ID, составы — лексикографически.

ExcelJS установлен только для Node как зависимость разработки; скрипт компилируется отдельно через tsconfig.scripts.json. Для транзитивной uuid добавлен override на исправленную ветку 11. Демонстрационный JSON сохранён побайтово в data/fixtures/demo-history.json; тесты M2 больше не зависят от рабочего JSON. README описывает команду, пример списка, добавление года и замену исходника. Валидаторы и статусы полноты не добавлены.
