## Ограничения

Физический телефон, повторный многоминутный эксперимент обновления кеша, полный перебор масштабов 10–200%, pinch и перетаскивание в этой задаче отдельно не проверялись; предыдущие проверки этих сценариев сохранены в отчётах UI и M6. В этой задаче приложение не менялось. Подтверждены текущие HTTP-заголовки и 304; свежий кеш после обновления может сохранять предыдущие данные до 10 минут. Уже открытая страница автоматически JSON не перечитывает.

Noindex относится к HTML; JSON доступен публично и собственного noindex не имеет. Поведение поисковых роботов не проверялось. Новых входных данных для дальнейшей публикации не требуется: push в main запускает workflow, сборка использует готовые JSON.
