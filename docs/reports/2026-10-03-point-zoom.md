# Приближение области до 100%

При масштабе ниже 100% двойной клик по свободному месту и Shift+клик по команде/фону возвращают 100%. Координата клика в исходном SVG помещается в центр окна диаграммы, с ограничением прокрутки на краях. Меняются только transform, размеры существующей обёртки и scrollLeft/scrollTop; renderer не вызывается. Ссылки и кнопки состава не перехватываются, при масштабе >=100% обработчик ничего не делает. Подсказка добавлена к кнопке процента.

Двойной клик по самой команде оставлен обычному выбору: первый клик уже выбирает команду и пересоздаёт SVG. Для приближения её области без выбора используется Shift+клик. Обычный выбор не задерживается ради распознавания двойного клика. Новых touch-обработчиков нет.

Изменены `src/diagram/zoom.ts`, `src/main.ts`, `tests/diagram-zoom.test.mjs`, `index.html`, README, описание диаграммы, требования и план задачи. Предыдущие незакоммиченные изменения масштаба сохранены. Данные, геометрия команд и зависимости не менялись.
