# Отчёт M3 — диаграмма и состав

Дата: 2 октября 2026 года. Статус: завершён на демонстрационных данных.

## Результат и приёмка

- SVG с d3-scale/d3-shape: годы 2026, 2025, 2024, 2022, 2021, 2020 слева направо; строки по месту и стабильному ID из M2. Места подписаны, длинные названия доступны полностью через доступную подпись, подсказку и панель.
- При загрузке выбран 2026:49804. Выбор другой команды сбрасывает игрока; панель показывает историческое название, название проведения, год, место и полный состав.
- Игрок выделяет свою полную цепочку; «Весь состав» возвращает все цепочки. Цвет зависит от ID, смещение — от позиции в полном составе и сохраняется при переключениях. Общие линии разведены шагом 3 px; пропуски пунктирные.
- Полные текстовые цепочки получены из M2, идут от старых лет к новым. Фильтр отбирает только исходные связи и не меняет панель или выбор. Факты не восстанавливаются из SVG.
- Диаграмма прокручивается в обе стороны; панель ниже неё, на телефоне одна колонка. Enter/пробел выбирают команду и игрока, фокус сохраняется при перерисовке; есть видимый контур и ссылка перехода к составу.
- Загрузка, техническая ошибка и пустой набор имеют текстовые состояния. Импорт, валидаторы и статусы полноты отсутствуют. Совпадающие полные имена получают ID в видимой и доступной подписи; отчества сохранены.

## Проверки

TDD: новые тесты состояния написаны первыми; запуск упал с ERR_MODULE_NOT_FOUND для отсутствующего selection.js. После реализации прошли все 16 тестов. Примеры проверяют последний год, минимум места при отсутствии первого, стабильное равное место, пустой набор, сброс игрока, отсутствие мутации и различение полного совпадения имён.

Фактические команды:

- `npm test` — 16 пройдено, 0 ошибок (существующие 13 и новые 3).
- `npm run typecheck` — успешно.
- `npm run build` — успешно, Vite 7.3.6; JS 15,27 kB, CSS 2,74 kB до gzip.
- `npm run dev` — sandbox запретил порт (EPERM); после разрешённого запуска сервер доступен на http://127.0.0.1:5174/ (5173 занят).

Браузер Codex, override 1280×900 и 390×844:

- Enter на 2024:27177 → панель «Призраки Коши · 2024», название проведения, шесть игроков, полные истории до/после выбора.
- Space на игрока «Александра Б.» (4270) → одна текстовая цепочка 2020–2026; после ограничения до 2025–2026 панель и игрок сохранены, одна видимая исходная связь. «Все годы» восстановила 5 связей, из них 1 пунктирная.
- «Весь состав» восстановил 6 цепочек; другая команда 2026:4109 показала место 6,5 и всех 8 игроков без обрезания состава.
- На телефоне панель читается в одной колонке, Enter на игроке оставляет одну цепочку; выбор команды и возврат состава также работают с клавиатуры. Ширина документа 375 при override 390 (особенность браузера), переполнения страницы нет. Область диаграммы имеет clientWidth 326, scrollWidth 1980; ArrowRight меняет scrollLeft.
- Внешний вид проверен визуально: подписи, приглушённый фон, раздельные цветные линии, пунктир и мобильная панель. Итоговый снимок: Override сброшен.

Пустота и техническая ошибка проверены чтением путей обработки и тестом начального пустого выбора, без подмены рабочего JSON в браузере. Полное совпадение ФИО проверено отдельным корректным тестовым примером: рабочий набор содержит совпадение имени/фамилии с разными отчествами.

Ревью: входные данные и функции M2 сохранены; DOM использует textContent; состояние по строковым ID отделено от фильтра, геометрия не задаёт факты; ограничений размера состава нет. Новых зависимостей не добавлено.
