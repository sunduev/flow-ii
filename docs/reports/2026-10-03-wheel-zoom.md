# Уровень 10% и зум колесом

Добавлен 10%, диапазон теперь 10–200%. Зум по двойному клику и Shift+клику полностью удалён вместе с обработчиком и прежней подсказкой. Alt/Option+вертикальное колесо над диаграммой переключает те же уровни: вверх увеличивает, вниз уменьшает. Исходная точка под курсором сохраняется на месте с ограничением у краёв. Кнопки продолжают сохранять центр.

Выбрана Alt/Option, чтобы Ctrl/Command и pinch оставались браузеру. Обычные wheel-события проходят без preventDefault. Мелкие события накапливаются до 80 px; строки считаются по 16 px, страницы — по высоте контейнера. Направление, пауза более 250 ms и обычное колесо сбрасывают накопление. Неотменяемые события, полосы прокрутки и пустая диаграмма не перехватываются. На границах повторный шаг не вызывает изменения DOM. При зуме renderer не вызывается, зависимости и данные не менялись.

Изменены `src/diagram/zoom.ts`, `src/main.ts`, `index.html`, `tests/diagram-zoom.test.mjs`, README, описание диаграммы, требования и план задачи. Исторические отчёты прежних изменений сохранены.

TDD: обновлённые тесты сначала упали на прежнем центрировании и отсутствующей обработке wheel. После реализации `npm test`: 51/51. Проверены обе оси, сохранение точки, обе стороны колеса, накопление/единицы, пауза/направление, исключение модификаторов, кликов и пустой диаграммы. `npm run build` (включает TypeScript приложения и скриптов) прошёл. `git diff --check` прошёл, diff прочитан.

Браузер Codex, production-сборка на реальном JSON. На временном локальном стенде тестовые кнопки отправляют синтетический WheelEvent с altKey; это проверка интеграции с настоящим DOM, не физического колеса. При viewport 1280×900 переход 100→125→100% обновляет кнопку процента, отменяет wheel и сохраняет тот же объект SVG; отклонение точки в исходных координатах около 0,1 px. При 10% дальнейшее уменьшение не меняет SVG/масштаб. Стенд расположен в /tmp, в production не включён, сервер после проверки остановлен.

В обычной production-странице: при 50% двойной клик по фону оставляет 50%; Shift+клик выбирает «Призраки Коши» без смены 50%. Нативное колесо прокручивает диаграмму при неизменном масштабе. Через кнопки доступен 10%: обёртка 660×398,1 px, кнопка уменьшения отключена. Viewport 390×844: 10%, ширина страницы и scrollWidth=390, сброс кнопкой через Enter возвращает 100%. Консоль без ошибок/предупреждений. Viewport сброшен.

Физические Alt/Option+колесо, тачпад, телефон и Safari не проверялись. GPU-профилирование не выполнялось; обработчик меняет только transform/размеры обёртки/прокрутку и состояние кнопок. Публикация и коммит не выполнялись.
