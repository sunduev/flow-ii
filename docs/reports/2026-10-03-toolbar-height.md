# Единая высота панели управления

Поля годов, «Компактно» и фильтр игрока уменьшены до одинаковых 36 px, шрифт 14 px, line-height 20 px. Правило ограничено панелью управления. Длинное имя фильтра остаётся в одну строку с многоточием при недостатке ширины; полное имя сохранено в доступной подписи. Изменён src/style.css, прежние изменения сохранены.

План: локальное CSS-правило → сборка и тесты → измерение размеров в браузере и клавиатура → ревью.

Проверки: npm run build — TypeScript и production-сборка успешно; npm test — 32/32; git diff --check — без замечаний. В браузере на 1280×900 и 390×844 все четыре элемента имеют высоту 36 px. На телефоне имя Максим Р. помещается целиком, ширина страницы 390 px без переполнения. Tab от «Компактно» и Enter снимают фильтр с возвратом фокуса. Viewport сброшен. Проверен телефонный размер в браузере, без физического телефона.
