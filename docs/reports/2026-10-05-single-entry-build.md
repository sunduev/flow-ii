# Одна точка сборки для N турниров

5 октября 2026 года. Выполнен согласованный компромисс: один исходный `index.html` и одна HTML-точка входа Vite, копии готового HTML в каталогах турниров, выбор JSON общим JS по пути страницы. Этот отчёт уточняет способ сборки из [предыдущей доработки](2026-10-05-multiple-tournaments.md); разделение XLSX и историй сохраняется.

## Изменения

- `vite.config.ts`: обычная конфигурация Vite без `.site/`, отдельного root, алиаса `/src` и списка HTML-входов. В общий JS включены только публичные настройки маршрутов; после сборки вызывается `writeSitePages`.
- `scripts/site-pages.ts`: читает готовый HTML, подставляет заголовки турниров, переносит относительные URL ресурсов на уровень выше, создаёт отдельную корневую страницу перенаправления. В корне отсутствуют общий JS и запрос истории.
- `src/model/tournament-page.ts`, `src/env.d.ts`, `src/main.ts`, `index.html`: выбор серии по точному пути, один запрос её JSON, заголовок страницы, перенаправление корня и адресов без слеша с сохранением query/hash. Каталог сайта определяется по URL общего модуля в `src/` или `assets/`. Неизвестный маршрут не выбирает серию.
- `tests/tournament-page.test.mjs`, `tests/tournaments.test.mjs`, `tsconfig.test.json`: маршрутизация, один JSON, три копии готового HTML, заголовки и пути ресурсов при абсолютном/относительном base.
- README, план, контракт, AGENTS и комментарий реестра описывают итоговое решение. Сохранён [план работы](../plans/2026-10-05-single-entry-build.md); временный каталог `.site/` удалён.

Преобразователь и реальные данные не менялись в рамках этого упрощения. Реальные данные второго турнира ещё не предоставлены.
