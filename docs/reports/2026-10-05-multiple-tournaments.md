# Независимые истории N турниров

5 октября 2026 года. Статус: локальная реализация завершена; публикация, commit и push не выполнялись. Реальные данные второго турнира пока не предоставлены.

## Результат

- ЧР расположен на `/flow-chr/chr/`; адрес без завершающего слеша перенаправляется на каталог. Корень `/flow-chr/` перенаправляет на ЧР, сохраняя query и hash в JavaScript-перенаправлении.
- `data/tournaments.json` задаёт N серий: ключ, название, список источников относительно проекта и адрес JSON относительно public. Ключ серии отделён от ID ежегодного проведения рейтинга.
- `scripts/site-pages.ts` создаёт страницы из одного `index.html` в игнорируемой `.site/`. Vite собирает их с общими JS/CSS. Корневая страница не подключает приложение и не запрашивает JSON. Реестр и источники в браузер не попадают.
- HTML турнира содержит только его название и относительный URL истории. Загрузчик выполняет один fetch; совпадающие ID в разных JSON не объединяются. Вычисления истории и диаграмма не изменены.
- ЧР перенесён в `data/tournaments/chr/sources.json`, `data/tournaments/chr/source/` и `public/data/chr/history.json`. Все 21 локальная XLSX сохранены и по-прежнему игнорируются Git.
- `npm run convert:xlsx -- <slug>` пересоздаёт только выбранную историю. Без аргументов — серия по умолчанию; режим двух произвольных путей сохранён. Dev/build/CI не запускают преобразование и не требуют XLSX.
- Добавление очередной серии описано в README: запись реестра, отдельные XLSX и метаданные, преобразование, обычная сборка. Между страницами нет меню или ссылок.

## Браузер

Итоговая production-сборка на `http://127.0.0.1:4173/flow-chr/`: перенаправление на `/flow-chr/chr/`, прямое открытие, перезагрузка и `/chr?test=1` → `/chr/?test=1` работают. Отображаются 1324 узла реального набора. Dev на порту 5174 также загружает страницу и все узлы без ошибок консоли.

Для проверки N временно добавлены `qa-second` и `qa-third` с отдельными корректными JSON и одинаковыми с ЧР ID. Сборка `npm run build -- --base=./` создала три независимые страницы с общими ресурсами. Стенд `node scripts/serve-quality.mjs` через PerformanceObserver зафиксировал:

| Страница | Единственный fetch |
| --- | --- |
| `/full/chr/` | `/full/data/chr/history.json` |
| `/full/qa-second/` | `/full/data/qa-second/history.json` |
| `/full/qa-third/` | `/full/data/qa-third/history.json` |

У тестовых страниц свои заголовки, имена и ровно два узла; данные ЧР не примешиваются. Прямой адрес второго без слеша и перезагрузка работают. Затем временные записи и JSON удалены; восстановлена обычная итоговая сборка только с ЧР.

На реальном ЧР Enter открывает состав Борского корабела 2026 и выбирает игрока «Максим Р.». Escape закрывает карточку; диапазон 2025–2026 сохраняет выбор и фильтр, возврат периода восстанавливает все годы. Space переключает компактный режим в обе стороны. На 390×844 состав открывается снизу, игрок выбирается клавиатурой, карточка/фильтр/период работают; ширина страницы и scrollWidth равны 390. Снятие фильтра возвращает фокус на «Компактно». Override сброшен. `/empty/chr/` показывает отсутствие результатов, `/error/chr/` — HTTP 503.
