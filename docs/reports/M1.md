# Отчёт M1 — основа проекта

Дата: 2 октября 2026 года. Статус: завершён, обязательные критерии выполнены.

## Результат и критерии

- Создан статический каркас Vite + TypeScript + CSS; зависимости d3-scale/d3-shape и их типы установлены, версии зафиксированы в package-lock.json.
- Команды установки, запуска, TypeScript, сборки и просмотра описаны в README. Повторная установка по lock-файлу выполнена успешно.
- Модель версии 1 описана в src/model/types.ts: строковые ID, поля проведения id/year/name, исторические название и состав, числовое дробное место. Контракт связан из README.
- Готовый JSON подключён загрузчиком с BASE_URL; HTTP-ошибки обрабатываются обычным сообщением. Валидаторов, импорта таблиц и ограничений размера состава нет.
- Страница явно обозначает условные годы и межгодовые события; показывает успешную загрузку и количества сущностей.
- Исходные JSON и конкретные ожидаемые цепочки в data/fixtures/ сохранены без изменений; из README доступны описание и машиночитаемые сценарии. Каталоги history, diagram и roster имеют отдельные описания ответственности для M2–M3.

## Фактические проверки

- `npm install --cache /private/tmp/chr-flow-npm-cache` — успешно; аудит без уязвимостей. Первоначальная установка со стандартным кэшем не прошла из-за прав записи, без изменения этого кэша использован отдельный временный каталог.
- `npm ci --cache /private/tmp/chr-flow-npm-cache --offline` — успешно; воспроизводимая установка по lock-файлу из уже скачанного кэша, аудит без уязвимостей.
- `npm run typecheck` — успешно.
- `npm run build` — успешно, Vite 7.3.6; статический результат в dist/.
- `npm run dev` — успешно на http://127.0.0.1:5173/ после разрешённого запуска вне sandbox; внутри sandbox открытие локального порта запрещено.
- Браузер: загружены 6 проведений, 90 команд, 574 игрока, 540 участий; видны сообщение успеха и пометка тестовых данных. Просмотрены настольный и телефонный размеры (override 390 × 844, фактическая ширина документа 375). Карточки на телефоне идут в две колонки, текст переносится; scrollWidth равен clientWidth, горизонтального переполнения нет.
- Клавиатура: Tab переводит фокус на единственную ссылку, контур фокуса виден. Полный сценарий выбора команды/игрока ещё не реализован и проверяется в M3.
- Однократный осмотр JSON через Node: schemaVersion 1; у проведения только id/year/name; место 2026:4109 равно 6.5; максимальный состав — 9. JSON в dist/data побайтово совпадает с public/data. Это проверка результата M1, не добавленный валидатор.
- Ревью исходников: модель отделена от загрузки и страницы; данные выводятся через textContent, история не вычисляется из DOM; отсутствуют лишние функции M2–M6 и runtime-проверки фактов.

## Ограничения и следующий этап

Git не инициализирован, репозиторий и коммиты не создавались. Unit-тесты для каркаса не добавлялись: вычислительные функции и TDD относятся к M2. Приложение M1 показывает загрузку набора, а не рабочую диаграмму M3. Публикация не выполнялась.

M2 может использовать src/model/types.ts, public/data/tournament-history.json и ожидаемые истории data/fixtures/history-scenarios.json; обязательные входы M2 доступны. Для M4–M5 ещё потребуются реальные XLSX каждого проведения, годы и названия; условная история не заменяет их. Для M6 потребуются целевой GitHub-репозиторий и доступ.
