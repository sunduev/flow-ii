5 октября 2026 года. По поручению пользователя каталог отменён: `/flow-chr/` снова перенаправляет на `/flow-chr/chr/`. Удалены разметка, стили и ветка запуска каталога. Сохраняются единый HTML-вход Vite, общий JS/CSS и отдельный JSON каждой серии. Корневое перенаправление использует `defaultTournament` реестра; текущая серия по умолчанию — ЧР.

В `main.ts` функция `start()` заменяет прежний верхний `try`; ошибки обрабатываются через `.catch()`. Это позволяет выйти после редиректа, сохранив исходные отступы всей логики диаграммы. Diff относительно HEAD: 16 добавленных и 4 удалённых строки, без массового сдвига. В CSS нет отличий от HEAD; исходный заголовок остаётся «Инфографика».

`@vite-ignore` сохранён с пояснением: `new URL('../', import.meta.url)` вычисляет URL каталога сайта во время работы приложения. Vite не должен рассматривать его как статический ресурс. Назначение маркера подтверждено по установленному Vite; он также предотвращает предупреждение о несуществующем ресурсе при сборке.
