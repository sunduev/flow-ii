# Очистка имён игроков и изображений отчётов

6 октября 2026 года. План выполнен локально в существующем репозитории. При реализации плана коммиты, push, новая публикация, изменение доступа и переписывание истории не выполнялись; до последующего поручения на фиксацию HEAD оставался 918e5a47b901e682afd503de5976b8198f70f706. После приёмки пользователь поручил создать локальный коммит и удалить отдельный план временного отключения публикации. Push и возобновление публикации не поручены.

## Изменения

- scripts/convert-xlsx.ts формирует players[].name непосредственно из отдельных колонок XLSX: имя целиком и первый Unicode code point фамилии в верхнем регистре с точкой. Отчество не попадает в JSON; пустые компоненты обработаны без новых проверок данных. src/model/types.ts описывает новую подпись.
- public/data/chr/history.json и public/data/studchr/history.json пересозданы по всем локальным источникам. ID, schemaVersion, составы, годы, места, названия и порядок сохранены. ЧР: 21 проведение, 420 команд, 2679 игроков, 1324 участия; СтудЧР: 26 проведений, 671 команда, 3813 игроков, 1194 участия.
- data/fixtures/source-snapshot.json и demo-history.json получили только новые подписи по исходным ID из XLSX ЧР 2026. Их условные истории сохранены. history-scenarios.json использует ./demo-history.json и сокращённые ожидаемые подписи.
- tests/convert-xlsx.test.mjs, tournaments.test.mjs и selection.test.mjs проверяют новый формат и различение коллизий по ID. Тестовые входные компоненты синтетические. UI уже использовал playerLabel и не потребовал изменения.
- AGENTS.md, README, контракт, актуальные требования, milestones, старые планы/отчёты и необязательный HTML-макет очищены от полных подписей игроков; исторические даты/результаты сохранены. Действующее правило отчества заменено. В документах отмечены приватный репозиторий и отключённый Pages по последней подтверждённой проверке исходного чата, без предположения о состоянии workflow. Отдельный план отключения удалён по последующему поручению пользователя.
- Все 67 старых изображений docs/reports удалены, ссылки и упоминания конкретных файлов убраны. Новые отчёты текстовые; постоянных скриншотов не создавалось.

## Проверки

TDD: после добавления ожидаемых сокращённых имён первый npm test дал 3 падения именно по прежним полным подписям. После реализации и в итоговом запуске — 77/77, без пропусков. Проверены пробелы, составные компоненты, ё, Unicode вне BMP, пустые компоненты, независимость от отчества, обновление имени последним годом, ведущие нули ID и изоляция серий.

Фактические команды: npm run convert:xlsx -- chr; npm run convert:xlsx -- studchr (обе повторены); npm test; npm run typecheck; npm run build; git diff --check. Все успешно. Дополнительно выполнена относительная сборка npm run build -- --base=./ для существующего QA-стенда; после приёмки повторена обычная production-сборка.

Сравнение с приватной временной копией исходных рабочих JSON и с HEAD для двух fixture-JSON подтвердило: различаются только players[].name, все остальные поля и массивы совпадают. Повторное преобразование и независимый convertSources дают побайтно одинаковый компактный JSON с завершающим переносом. Оба JSON финального dist побайтно совпадают с public/data. Независимое ревью родителя повторно подтвердило неизменность остальных данных четырёх JSON, отсутствие изображений отчётов, отсутствие исходных полных подписей игроков в текущих текстах и неизменность HEAD.

Поиск выполнен по полной карте отдельных колонок всех 47 локальных XLSX, включая исторические варианты имён и кандидаты фамилий, в текущих отслеживаемых текстах и новых планах; архивов исходников в Git нет. Полные сведения локальных ignored-XLSX сохранены. Разрешённые исключения проверены по контексту: авторская подпись футера и историческое название команды СтудЧР 2026:84143, содержащее имя человека. Имена людей внутри названий команд не переименовывались. Скрытых справочников полных имён игроков не добавлено.

- СтудЧР: Детективы для элит 2026 (2026:100048), собственный игрок 135968 «Денис П. · ID 135968»; на desktop выбрано участие той же команды 2025 с семью игроками. Период до одного 2026 скрыл выбранный 2025, сохранил фильтр; возврат периода восстановил доступ к составу. Фильтр, Escape, снятие крестиком и компактность работают клавиатурой.
- «Все составы» переключается клавиатурой, сокращённые коллизии в реальных составах имеют исходные ID. «Первая сборная» 2026 показывает 6,5 и восемь игроков. На телефоне ширина страницы/scrollWidth 390, нижняя карточка и все подписи читаются; viewport после проверки сброшен.

Локальные HTTP-ответы curl побайтно совпали с очищенными JSON. DOM карточек/фильтра и доступные подписи используют только сокращённые имена с ID.

## Ограничения

Старые коммиты, ранее размещённые Actions-артефакты, внешние кеши и чужие копии не очищались. Репозиторий и Pages в этом поручении не изменялись: последняя известная проверка — private=true и has_pages=false; состояние публикующего workflow остаётся отдельно неподтверждённым. Исходные ID допускают сопоставление с рейтингом и не обеспечивают анонимность. Физический телефон и другие браузеры не проверялись.
