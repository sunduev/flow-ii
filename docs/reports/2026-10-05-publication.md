# Проверка актуальной публикации

5 октября 2026 года. Документация обновлена по фактическому состоянию GitHub Pages. Новая публикация в рамках этой задачи не выполнялась.

## Опубликованная версия

Локальный `HEAD` и `origin/main` — `b96bfda094e99f7612875867e712058cbed1c3cc`. Workflow [Publish GitHub Pages, run 37284193379](https://github.com/sunduev/flow-chr/actions/runs/37284193379) для этого SHA имеет `status: completed`, `conclusion: success`. В версию входят поддержка N серий, СтудЧР и исправление склонения счётчиков.

- [ЧР](https://sunduev.github.io/flow-chr/chr/) — 21 проведение за 2001–2019, 2025–2026, 420 команд, 2679 игроков, 1324 участия.
- [СтудЧР](https://sunduev.github.io/flow-chr/studchr/) — 26 проведений за 2001–2026, 671 команда, 3813 игроков, 1194 участия.
- [Корень](https://sunduev.github.io/flow-chr/) содержит HTML перенаправления на `./chr/`; JavaScript сохраняет query и hash. Приложение и JSON в корневом HTML не подключаются.

Обе страницы и оба JSON получены с HTTP 200 и `Cache-Control: max-age=600`. Заголовки страниц — «Инфографика ЧР» и «Инфографика СтудЧР», обе подключают общий `/flow-chr/assets/index-uGSqSQ9b.js`.

## Проверки

Статус прочитан командой `gh run list --repo sunduev/flow-chr --workflow pages.yml --limit 3 --json databaseId,status,conclusion,headSha,url` через сохранённый доступ проекта. Публичные HTML и JSON загружены `curl -fsSL`, заголовки страниц и JSON сохранены с `-D` во временные файлы. `shasum -a 256` подтвердил побайтное совпадение локальных и публичных JSON:

| --- | --- |
| `public/data/chr/history.json` ↔ `/flow-chr/data/chr/history.json` | `9f8db60c253385b21b7ab0e1d5376f209ca81fe67a32a0fa46bdcaa755095f0c` |
| `public/data/studchr/history.json` ↔ `/flow-chr/data/studchr/history.json` | `25f1dcb4e5b9eca8d5e6aad3425fd7dafac1c3b1a378b77d8ca61a816d5d2e50` |

Обновлены README, AGENTS.md, основной план, контракт данных и ссылки из задания/отчёта M6. Убраны утверждения о неопубликованном расширении и отсутствии данных второй серии. Процедура описывает преобразование выбранной серии, общую публикацию, проверку workflow для отправленного SHA и сравнение обеих историй.

`git diff --check` прошёл; локальные ссылки в семи изменённых документах разрешаются в существующие файлы. Числа проведений, команд, игроков и участий сверены с соответствующими массивами локальных JSON.

Результаты первоначальной публичной приёмки и эксперимента с кешем сохранены в [M6](M6.md); предыдущие отчёты реализации описывают состояние на момент своих задач.
