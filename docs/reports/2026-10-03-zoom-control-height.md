# Высота кнопок масштаба

По комментарию браузера воспроизведено: кнопки зума имели высоту 40 px, остальные элементы панели — 36 px. Причина: min-height: 40px в `.zoom-controls button` перекрывал общий height: 36px.

В `src/style.css` удалён отдельный min-height: кнопки используют общую высоту панели. Проверено в текущем пользовательском состоянии на localhost:5173: все кнопки и select имеют 36 px, выбор UFO 2013 и фильтр игрока сохранены. В viewport 390×844 кнопки также 36 px, ширина страницы и scrollWidth=390; override сброшен.

`npm run build` (включает TypeScript) и `git diff --check` прошли. Это только CSS-правка, новые unit-тесты не требуются; поведение не менялось. Остальные незакоммиченные изменения сохранены.
