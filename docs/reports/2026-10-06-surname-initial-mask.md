# Маска игроков «Фамилия И.»

Дата: 6 октября 2026 года. Локальная задача завершена.

Изменён форматтер scripts/convert-xlsx.ts: полная фамилия и первый Unicode code point имени в верхнем регистре с точкой. Составные фамилии сохраняются целиком. Пустые компоненты обрабатываются по контракту, отчество игнорируется. Последнее проведение по-прежнему задаёт справочную подпись, совпадения не объединяют ID.

Обе реальные истории пересозданы из доступных локальных ignored-XLSX через npm run convert:xlsx -- chr и npm run convert:xlsx -- studchr. ЧР: 21 проведение, 420 команд, 2679 игроков, 1324 участия; СтудЧР: 26 проведений, 671 команда, 3813 игроков, 1194 участия. Два fixture обновлены по ID из исходного XLSX ЧР 2026. Форматирование JSON сохранено: реальные JSON компактные с завершающим переносом, fixture сохранили прежние отступы.

Обновлены AGENTS.md, README, docs/plan.md, docs/data-contract.md, src/model/types.ts, README fixtures, history-scenarios, синтетические XLSX/selection/tournaments тесты и необязательный HTML-макет. В milestones добавлена ссылка на текущую маску; прежние критерии и приёмка сохранены. Старые планы и отчёты не переписывались. Авторская подпись, команды, noindex, хостинг и remote не менялись.

## Проверки

TDD: ожидаемые подписи изменены до форматтера; npm test подтвердил два падения именно из-за прежней маски. После минимального исправления и актуализации fixture-сценариев npm test: 77/77, без пропусков. Проверены крайние пробелы, составные фамилии, ё, Unicode вне BMP, пустые поля, независимость от отчества, последнее проведение и разделение одинаковых подписей по ID.

npm run typecheck, npm run build и git diff --check успешны. Структурное сравнение с HEAD после удаления исключительно players[].name подтвердило глубокое равенство четырёх JSON, включая порядок всех массивов. Изменены 2679, 3813, 574 и 574 подписи соответственно. Независимая проверка родителя подтвердила сравнение, побайтное равенство dist/public JSON обеих серий и один noindex,nofollow в head каждого из трёх HTML (корень, ЧР, СтудЧР). Тест выбранной серии подтверждает изоляцию чтения и записи JSON.

Браузерный smoke на production preview: обе серии при 1280×900 и 390×844, реальные карточки состава, выбор команды мышью, Enter/Space для состава и игрока, Escape, снятие фильтра, сохранение фильтра при смене периода, Tab между управлением. ЧР: Борский корабел 2026, фильтр Руссо М.; ФИЗкультурный ТЕХникум 2026 показывает совпадающие подписи с ID 147115, 195643, 55997. СтудЧР: Эквестрия гёрлз 2026, фильтр совпадающей подписи с ID 242369. Подписи читаются на обоих размерах, состав из восьми игроков виден на телефоне. Консоль warn/error пуста. Скриншоты просмотрены только в инструменте, файлы не сохранялись. ## Ограничения

Физический телефон и другие браузеры не проверялись; выполнен ограниченный smoke затронутого поведения. На момент локальной приёмки commit, push, публикация, перенос репозитория и переписывание Git не выполнялись. После приёмки пользователь отдельно поручил локальный коммит; push и публикация не поручены. Исходные ID сохранены, сопоставление с рейтингом возможно. Игнорируемые XLSX не добавлены в Git или public; полные имена и отчества игроков в новые артефакты не записаны.
