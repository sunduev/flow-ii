- [API истории](../src/history/README.md) и [диаграмма](../src/diagram/README.md) — описание текущего кода.
- [Тестовые данные](../data/fixtures/README.md) — условные сценарии, отдельно от реальной истории.

M1–M6 завершены. [Задания этапов](../milestones/), [планы задач](plans/) и [отчёты](reports/) сохраняют требования и результаты на дату соответствующей работы.
